# BeastBase: Python Guild Manager

A clean, beginner-friendly Python project demonstrating the practical usage of **non-primitive data structures** (`List`, `Tuple`, `Dictionary`, and `Set`) by managing an RPG monster guild roster.

---

# Concepts Covered

| Data Type | Purpose in Project | Key Characteristic |
| :--- | :--- | :--- |
| **`Tuple`** | Stores headquarters info & combat stats (`HP`, `ATK`) | Immutable (cannot be changed after creation) |
| **`Set`** | Manages monster elemental affinities | Unique collection (automatically removes duplicate entries) |
| **`Dictionary`** | Holds structured monster profile attributes | Key-value mapping for organized record lookup |
| **`List`** | Serves as the dynamic guild roster | Ordered, mutable collection that allows additions |
